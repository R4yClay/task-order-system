# Task Order System

Full-stack веб-приложение для управления проектами и задачами.

## Возможности

* регистрация и авторизация пользователей;
* управление пользователями;
* создание и управление проектами;
* создание, изменение и отслеживание задач;
* управление статусами задач;
* аналитика по проектам и задачам;
* REST API;
* автоматические тесты;
* запуск проекта через Docker Compose.

## Технологии

### Backend

* Python
* FastAPI
* SQLAlchemy
* PostgreSQL
* Pydantic
* JWT-аутентификация
* Pytest

### Frontend

* React
* TypeScript
* Vite
* CSS

### DevOps

* Docker
* Docker Compose
* GitHub Actions

## Архитектура

Проект разделён на две основные части:

```text
task-order-system/
├── backend/        # REST API и бизнес-логика
├── frontend/       # пользовательский интерфейс
├── docker-compose.yml
└── .github/        # CI/CD
```

Backend предоставляет API для работы с пользователями, проектами, задачами, авторизацией и аналитикой. Frontend взаимодействует с API и предоставляет веб-интерфейс для управления системой.

## Запуск

Проект можно запустить с помощью Docker Compose:

```bash
docker compose up --build
```

После запуска frontend и backend становятся доступны локально согласно настройкам проекта.

## Назначение

Проект создан как практическое full-stack приложение для изучения разработки современных веб-сервисов на Python и TypeScript, построения REST API, работы с базами данных, авторизацией, Docker и автоматическим тестированием.
